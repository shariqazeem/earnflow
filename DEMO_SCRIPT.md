# Recording Tips

1. **Browser setup:** Use Chrome, zoom to 90%, window at ~1280x800
2. **Clean state:** Clear localStorage, disconnect wallet first so you start from welcome screen
3. **Slow movements:** Move mouse slowly and deliberately. No jittery clicks.
4. **Pause on key moments:** Let animations complete before moving on
5. **WiFi:** Make sure connection is stable — the quotes need to load
6. **MetaMask:** Have it ready on Base chain before recording
7. **Don't rush:** 75 seconds of smooth flow beats 45 seconds of chaos

# Adding Captions (easiest method)

1. Record raw screen video (no captions)
2. Open CapCut (free, capcut.com) or iMovie
3. Add text overlays at each timestamp above
4. Use white text with slight black shadow, positioned at bottom
5. Font: Inter or SF Pro (or any clean sans-serif)
6. Export at 1080p

# If no time for captions

Just record the raw screen video. A clean, smooth flow speaks for itself.
The tweet text provides all the context judges need.
